# Cognivantha 🚦
**Crowdsourced Civic Issue Reporting & Resolution System (SIH25031)**

Cognivantha is a dual-interface platform designed to bridge the gap between citizens and local authorities. It gamifies civic reporting by rewarding users for legitimate infrastructure complaints while equipping authorities with a smart triage dashboard to prioritize critical issues.

## 🚀 Features (Prototype)
- **Public Portal:** Users can log in, report issues (simulated live photo/GPS), and earn Civic Reward Points for resolved reports.
- **Authority Dashboard:** A triage feed featuring auto-calculated Priority Levels (based on incident scale and reporter trust scores).
- **Smart Status Tracking:** Real-time updates from 'Pending' to 'Resolved' or 'Flagged'.

## 🛠️ Tech Stack
- **Frontend:** React + Tailwind CSS
- **Icons:** Lucide React
- **State Management:** React Context / LocalStorage (Mock DB for prototyping)
- **Mapping:** Leaflet / Mapbox (Under Development)
